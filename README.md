Ji.dev – Software Engineering Portfolio
A modern, interactive, and minimalist web portfolio showcasing robust system architectures, complex backend integrations, and full-stack applications. Built with a focus on premium user experience (UX), fluid animations, and clean aesthetics.

🚀 Tech Stack
This project is built using modern frontend technologies to ensure performance and scalability:

Framework: Next.js (App Router)
Styling: Tailwind CSS
Animations: Framer Motion
UI Components: Aceternity UI
